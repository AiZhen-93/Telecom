SpeedTest Tools

測速工具

SpeedTest(OOKLA) 全球常用測速平台，可測下載、上傳、Ping，並自動選擇鄰近測速節點。 SpeedTest(Cloudflare) Cloudflare 提供的網路品質測試，可查看延遲、下載、上傳與封包品質指標。 Fast.com Netflix 提供的簡潔測速服務，適合快速檢查串流與一般下載速度。 台大測速 台灣大學測速服務，適合用來觀察連往台灣學術網路節點的連線表現。 HINET HTTP傳輸測試 中華電信 HiNet 的 HTTP 傳輸測試，透過實際的檔案下載來檢視下行網速表現，可依據需求選擇不同大小的測試檔案。 網路面板 可以進行長時間連續的下載測速。請注意，這可能會快速消耗您的流量，並使裝置發燙。

CA Combos

CA組合查詢

CA Combos 可以根據手機型號查詢其modem型號和CA組合資料。不過此網站基本已經不再更新。 UE Capability Parser 一個可以讓使用者上傳自己手機連線能力log檔的平台，透過信令正規化解析，轉換成易於閱讀的裝置連線能力和CA組合報表。 Peter手機電信表格 由mobile01知名作者 Peter大 所自行整理的各式手機CA組合表格，以及各電信方案AMBR、出國上網卡等實用資訊。

Cell Towers Searching

基站查詢

NCC資料庫 可依縣市路段查詢電信基地台的執照發行情形，檢視其頻率和功率等資訊。
Cellmapper 專為電信愛好者打造的基地台資訊地圖。透過手機的app蒐集周邊的站台數據，並以地圖的方式呈現站台分布，推估位置，並可詳細檢視其站台號碼、頻段、PCI及涵蓋範圍等詳細資料。 觀看教學
OpenCellId 世界上最大的公開基站資料庫。儘管台灣這邊的數據已經停止更新，但仍可以查詢到過去的站台資料，甚至是2G/3G。

DT Apps

路測Apps

Network Signal Guru Network Signal Guru是一款極為強大的專業路測軟體，能測量基地台各式訊號指標、檢視連線頻段及CA載波聚合狀態，更能解析層三信令供各式站台參數檢視，還具備所頻段、鎖網路、鎖頻點及腳本測試等進階功能。 手機必須ROOT才可使用完整功能，部分功能需付費。 觀看教學
NetMonster NetMonster是一款直觀的訊號檢視軟體，可以直接看到站台的各項訊號指標，明確的CA載波聚合組合顯示，其進階版更提供以TA值反推站台位置的功能。 CA頻段組合必須要在RRC連接狀態才會準確。部分手機會有CA、頻寬顯示異常、雙卡資訊干擾等情形。 觀看教學
Netmonitor NetMonster是一款介面友善的訊號檢視軟體，可檢視站台各項訊號指標，透過圖表和色調呈現訊號變化及強度，亦有儀表和地圖等介面。 部分手機會有頻寬顯示異常、雙卡資訊干擾等情形。 G-NetTrack Pro G-NetTrack Pro是一款可以記錄手機各項訊號指標數值變化的軟體，也是很多電信工程師愛用的app之一。 此為付費版本，免費版請下載G-NetTrack Lite。 nPerf nPerf是一款可以評測上網實際體驗指標的app，並有地圖功能可以記錄路段的訊號涵蓋情形。 已ROOT的裝置無法上傳測試數據。 Opensignal Opensignal是一款可以進行測速，並透過地圖共享訊號涵蓋的軟體。其官方也會根據大量用戶的測試結果發布電信業者的網路評比報告。 此軟體無法檢視站台和頻段資訊。

Maps

地圖Apps

A-GPS Tracker A-GPS是一款可以記錄GPS軌跡的軟體，可用於路測路線檢視及匯出GPX檔。儘管它已經在Play商店下架，但仍可以下載到apk安裝並正常運行。 OsmAnd 開放街區地圖的官方app，完整的離線向量地圖，適合在預期收訊較弱甚至是沒有網路的路段使用，並擁有多項自訂設置和外掛套件可使用。

Forums

論壇社群

Mobile01電信版 台灣消費者通訊討論園地，偏向實際收訊經驗分享與門號資費優惠方案討論。 PTT通訊版 台灣最活躍的通訊討論區之一，以文字討論為主。最新的電信新聞稿、NCC政令、資費整理通常能在這裡找到。 telecomHall 國際性的電信工程師論壇，主要使用英文交流。工程技術導向，討論偏向技術層面和實務部署與維運。 通信人家園 中國大型的通信技術論壇，長期聚焦電信工程與教育，中文技術資料非常豐富。
